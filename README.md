# Here · 我在这里

一个在 Mac 桌面上陪你工作、休息的小角色。基于 Electron 和 Canvas，当前公开版本为 **1.5.5-public.1**，由本地 1.5.5 整理而来。

## 有什么好玩

- 透明置顶，人物以外区域鼠标穿透；拖动摆放位置。
- 点击互动台词，连续点击有不同反馈；灰套装拎起时蜷缩、转螺旋眼。
- 陪你打字、托腮思考、盖被睡觉；挥手、飞吻、伸懒腰和闪身步彩蛋。
- 春夏 / 秋冬两套服装，可跟随月份或手动选择。
- 自动跟随作息，也可手动选择状态；支持安静模式。
- 本地模式运行，当前关闭远程消息连接，不需要填写 API Key。

## 从源码运行

需要 macOS、Node.js 与 npm。进入项目后：

```bash
cd app
npm ci
npm start
```

右键点击人物，或点击系统菜单栏的 Here 图标，打开菜单。按住人物即可拖动。

## 测试与打包

```bash
cd app
npm test
npm run dist
```

通用 Mac 安装包输出到 `app/dist/Here.dmg`，目标为 Intel 与 Apple 芯片。构建需要 macOS、Apple 命令行工具，并能访问 Electron 依赖下载服务。

当前使用本地临时签名，没有 Apple 开发者公证；安装提示以系统实际显示为准。仅从你信任的来源安装。

## 公开版本的范围

保留当前 2D 桌宠的运行代码与必要素材；移除了私人称呼、固定生日触发和私人中转地址。不包含历史试验、VRM 模型、私人连接文件或云端部署资料。远程消息相关代码保留，但主入口关闭该功能。

`app/assets/台词.json` 可直接编辑台词。动作配置在 `app/assets/sprites-v2/actions.json`，闪身步时长在 `app/assets/motions/grey-dash-v29/timings.json`。

## 素材与许可

角色与动画来自本项目制作过程中的 AI 辅助素材迭代。公开目录不含初音等第三方角色模型。当前未授予通用开源许可，沿用 `UNLICENSED`；代码可公开阅读，不代表角色、图像或代码获准再分发或商业使用。第三方依赖遵循各自许可。
